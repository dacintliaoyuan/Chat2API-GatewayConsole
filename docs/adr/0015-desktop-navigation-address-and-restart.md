# 桌面控制台导航分组、地址入口与网关重启

## 状态

已接受（2026-11-22）

## 背景

桌面控制台首版侧栏为五项纯文字导航，每页标题行右侧都显示 `http://127.0.0.1:<port>` 与 `/v1` 两个复制 chip，网关异常时只显示状态与错误文本。与 Magpie 参考界面相比有三处差异：导航没有图标与分组，地址 chip 在每页重复，网关故障没有恢复入口；同时请求诊断页在 1060×720 下分析卡占去约 340px，请求列表只剩约 2 行。

## 决策

### 导航

- 侧栏改为「图标 + 文字」，分两组：观测（总览、请求诊断、运行日志）与设置（设置、帮助）。组间额外 12px 间距，不显示组标题。
- 图标使用 Lucide v0.468.0 原始 SVG（`layout-dashboard`、`search`、`scroll-text`、`settings`、`circle-help`；0.468.0 中 `help-circle` 已改名为 `circle-help`），与 `desktop/ui/icons/` 现有图标同源同许可。
- 图标 16px；选中态 `accent-strong`，未选中 `muted`，hover `rail-ink`。rail 宽保持 196px。
- compact rail（84px）只显示图标，悬停 tooltip 显示文字；点击仍然直接跳转，不画蓝色焦点框。
- 深色主题选中态改用 `accent-soft`（`#0b2946`），与浅色 `#e8f2ff` 同一语义。

### 地址入口

- 地址 chip 只在总览标题行保留（`http://127.0.0.1:<port>` 与 `/v1` 两个可复制 chip）。
- 设置页网关卡保留「模型 API 地址」行，复制按钮带可见「复制」文字；请求诊断、运行日志、帮助页去掉标题行 chip。

### 请求诊断页信息密度

- 请求列表 `min-height: 240px`（约 4–5 行），页面可滚动；KPI 常驻（compact 2+2+1），图表按列表可用高度折叠；失败筛选只折图，不折 KPI。
- 分析卡内的选择提示并入状态行：状态行显示「本页 N 条」与悬停读数、键盘提示、更新时间；失败数只在指标卡用 `bad` 色（大于 0 时），不与「本页」混口径。
- 指标卡与图表标题标注「所选范围」；大数字按亿/万显示，精确值保留在 `token_count`/`request_count`。

### 网关重启

- 网关卡在失败状态旁提供「重启网关」，复用 `gateway.rs` 的 `restart`。
- 点一次变「确认重启？」并给出确认/取消，3 秒内无第二次点击恢复原状；重启期间网关卡显示「正在重启…」，失败给出原因。

## 后果

- 新增四个 Lucide 导航图标文件；`icons.slint` 的 `AppIcon` 增加对应 kind。
- `main.slint` 的 `nav-entries` 增加图标与分组字段，`NavItem` 支持图标；compact rail 只显示图标。
- 标题行地址 chip 只在总览渲染；设置页复制按钮改为带「复制」文字。
- 请求页状态行与指标卡保持各自口径；失败数用 `bad` 色。
- 网关卡新增重启确认状态与「正在重启…」反馈；`gateway.rs` 的 `restart` 增加公开入口。
- 验证：desktop headless 测试覆盖导航分组、compact 图标、地址 chip 可见性、列表 `min-height`、重启确认与状态；截图覆盖浅色/深色与 1060×720、540×420。
