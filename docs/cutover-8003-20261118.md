## 部署

```bash
cd /root
bash um-cloud-deploy/update.sh \
  --release /root/um-share-s2-20261118a.tar.gz \
  --sha256 <b2fe707d…> \
  --drain-budget 900 \
  --health-port 8003
```

顺序：停 cloudflared → drain（`in_flight:0`）→ host-stop → 停 console → 切 `current` → 启动 → 健康门。

部署后 `current = /opt/um-share/releases/s2-20261118a`，`previous = s2-20261117b`。
