# 桌面 UI 评审偏好与评分口径

给独立 UI 评审员（或视觉复核 agent）的固定口径。评分按 10 条 Nielsen 启发式、每条 0–4 分；下面这些是用户已经定下的偏好，**不算缺陷、不扣分**。

## 已定偏好（不要当问题报）

- **侧栏导航**：Lucide 图标 + 文字，分两组（观测：总览/请求诊断/运行日志；设置：设置/帮助），不显示组标题；compact rail 只显示图标 + tooltip。
- **地址 chip**：只在总览标题行保留 `http://127.0.0.1:<port>` 与 `/v1` 两个可复制 chip；设置页保留「模型 API 地址」行。
- **请求页**：列表 `min-height: 240px`、页面可滚动、分析卡默认展开；失败数只在指标卡用 bad 色；状态行保留「本页 N 条」。
- **不做**：费用、自定义日期范围、供应商/账号/Agent/用途筛选。
- **已加入（#145 parity 后）**：导出 CSV（请求列表与用量两处）；请求列表空态禁用导出，并在 tooltip 说明「当前列表没有可导出的请求」。
- **术语**：「网关状态」「登录状态未知」「原始日志」「输出速度（整次平均）」是已定措辞。
- **深色选中态**：`accent-soft`，和浅色同语义。

## 评分只看实现与偏好的冲突

- 偏好本身（例如「侧栏有图标」）不是扣分项；扣分只针对实现偏离偏好或违反启发式的地方。
- 预览夹具的合成数据必须按产品实际格式生成（千分位/亿、本页口径），否则评分员会把夹具文案当成产品缺陷。
- 截图与动效帧取自 `output/impeccable-ui-review/`；真实 App 只用于手动验收（主题、剪贴板、托盘）。
