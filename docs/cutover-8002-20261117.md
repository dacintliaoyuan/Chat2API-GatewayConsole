## 切流

`update.sh` 会重启 8003，本票明确要求不重启 8003，因此使用新 release 的
`install.sh --no-start` 安装文件与 unit，再只切换控制台 unit：

```bash
cd /root/um-share-s2-20261117a
bash um-cloud-deploy/install.sh \
  --release-dir /root/um-share-s2-20261117a \
  --version s2-20261117a \
  --skip-apt --no-start

install -m 0644 /root/um-share-s2-20261117a/um-cloud-deploy/systemd/um-share-console-python.service \
  /etc/systemd/system/um-share-console-python.service
systemctl daemon-reload
systemctl stop um-share-console.service
systemctl start um-share-console.service
```

结果：

- `um-share-console.service` active，Main PID 为 `um-console`，ExecStart 为
  `/opt/um-share/bin/um-console --mode production --bind-port 8002`。
- `um-share-console-python.service` inactive（回滚单元已安装，未启动）。
- 监听只有 `127.0.0.1:8002` 与 `127.0.0.1:8003`；`/ready` 为 200。

## 回滚演练

命令（云机，root）：

```bash
/opt/um-share/venv/bin/python /root/cutover_gate.py console-rollback-drill \
  --execute --timeout 60 \
  --env-file /etc/um-share/console.env \
  --json > /root/console-rollback-drill.json
```

演练顺序与结果：

1. `systemctl stop um-share-console.service`（Rust 8002）：passed。
2. 临时把 `/etc/um-share/console.env` 的 `USAGESRV_PORT` 改为 8096（其余行原样保留），
   `systemctl start um-share-console-python.service`：passed。
3. 等待 `127.0.0.1:8096`：passed。
4. `http://127.0.0.1:8096/health`：200。
5. `http://127.0.0.1:8003/ready`：200。
6. `systemctl stop um-share-console-python.service`：passed。
7. 恢复 `console.env` 原始字节，`systemctl start um-share-console.service`：passed。
8. 等待 `127.0.0.1:8002`：passed。
9. `http://127.0.0.1:8002/health`：200。
10. `http://127.0.0.1:8003/ready`：200。

结果：`console_rollback_drill.status=passed`，`executed=true`，`restored=true`；没有删除或新建 release；
`console.env` 的 `USAGESRV_PORT` 已恢复为 `8002`。
